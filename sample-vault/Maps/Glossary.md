# General Glossary

Everyday terms used across this vault. Contrast with [[Engineering/Glossary|Engineering Glossary]].

- **MOC** — Map of Content; an index note like [[Maps/Engineering MOC|Engineering MOC]].
- **Daily note** — a note named by date, e.g. [[Daily/2026-09-06|2026-09-06]].
- **Embed** — transclusion written `![[Note]]`.
